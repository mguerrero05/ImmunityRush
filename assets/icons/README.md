## Tips for the sheet (so it slices cleanly)
- **Transparent background** (PNG with alpha) so the icons sit on the maze floor without a box around them.
- Icons laid out on a **simple grid** (e.g. 3 across × 2 down, or 6 in a row) with even spacing — easiest to slice.
- Roughly **square** icons, similar size to each other.
- Any resolution is fine (bigger = crisper); ~128px per icon or larger is great.
