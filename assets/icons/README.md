# Custom game icons

Drop your icon art here. Either:
- **One sprite sheet** named **`icons.png`** with all icons on a simple grid, OR
- **Individual PNGs** (any names) — I'll view them and identify each.

I'll **look at the art, identify what each icon is, and map it to the right game
item** (then show you the mapping before wiring it in).

## The icons the game uses

These appear in the **maze** and the **Hospital Sprint**. Several overlap (heart,
family, star), so the unique set is:

### Pickups / good (collect these)
1. **shield** — Vaccine Shield (maze)
2. **syringe** — Vaccine Booster (sprint) / vaccine
3. **heart** — Heart / health (maze + sprint)
4. **family** — Family Token (maze + sprint)
5. **star** — Wellness Star / Boost (maze + sprint)
6. **speed** — Speed Boost / lightning (maze)
7. **energy** — Energy / stamina (sprint)

### Germs / obstacles (avoid these)
8. **germ** — the flu virus (maze hazards)
9. **barrier** — Sick-Day Barrier (sprint, low obstacle you jump)
10. **calendar** — Cancelled Plans (sprint, low obstacle you jump)
11. **cloud** — Low-Energy Cloud (sprint, high obstacle you duck)

You don't need all 11 — the **core** ones are the pickups (1–7) and the **germ**
(8). The three sprint obstacles (9–11) are optional; if you don't supply them I'll
keep the current look for those.

## Tips so it slices/maps cleanly
- **Transparent background** (PNG with alpha) — no box behind the icon.
- If it's ONE sheet: lay icons on an even **grid** (e.g. 4×3 or a row), similar
  sizes, roughly square. If you can, tell me the layout ("top row left→right: …").
- ~**128px per icon or larger** is great (bigger = crisper).
- If individual files, transparent square PNGs are perfect.

Once the art is in this folder, tell me — I'll view it, propose the mapping, and
after you confirm I'll slice + wire it into the maze and Hospital Sprint.
