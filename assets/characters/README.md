# Player character art

Drop your two character images here:

- **`male.png`** — the man character
- **`female.png`** — the woman character

These become the player you move in the maze (and the Customize preview + HUD portrait).

## Requirements
- **PNG with a fully transparent background** (no box/floor behind the character).
- **Full body, standing, facing the camera**, friendly/neutral pose, **arms at the sides**
  (not crossed — reads better while walking).
- **Centered** horizontally, **feet at the very bottom edge**, head near the top with a small margin.
- **Same framing, scale, and size for both files** so they swap cleanly.
- Style to match the home-screen nurses: **blue SHN scrubs, stethoscope, SHN badge**, smooth 3D cartoon look.
- **Portrait ~2:3**, e.g. **600×900** or larger (bigger = crisper). Same dimensions for both.
- Optional: a subtle soft shadow directly under the feet is fine; keep everything else transparent.

The character always faces the camera; walking left just mirrors the image, so only ONE pose per
gender is needed.

Note: with fixed images, the skin/hair/eye/scrub COLOUR options don't apply — Customize becomes
"Man or Woman." Once both files are here, tell me and I'll wire them in.
